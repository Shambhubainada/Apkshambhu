SHAMBHU SHED APK PROJECT

This project wraps https://shambhudayal1.netlify.app/ as an Android app named SHAMBHU SHED.
It includes the SHAMBHU SHED warehouse logo as the launcher icon.

BUILD:
1. Upload this folder to a GitHub repository.
2. Open Actions > Build SHAMBHU SHED APK > Run workflow.
3. After it finishes, open the workflow run and download the artifact named SHAMBHU-SHED-debug-apk.
4. Extract app-debug.apk and install it on Android.

Note: The APK loads the live Netlify site, so website changes appear in the app automatically. Internet is required.
